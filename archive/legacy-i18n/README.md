# Legacy i18n snapshot

Archived from the removed nested duplicate (`GoDrive/GoDrive/`) on 2026-06-08.

## Contents

| File | Purpose |
|------|---------|
| `i18n.js` | Monolithic embedded dictionary (77 core UI keys × FR/EN/AR) used to regenerate `public/js/i18n-core.js` |
| `i18n-content.js` | Historical page-content dictionary snapshot at time of duplicate removal |

## Canonical sources (use these)

- **Core UI:** `public/js/i18n-core.js`
- **Page content:** `public/js/i18n-content.js`
- **Runtime bundles:** `public/js/i18n/{fr,en,ar}/*.json` (generated by `npm run build:frontend`)

## Recovery command

Only needed if `i18n-core.js` is lost or corrupted:

```bash
npm run i18n:core
```

`scripts/generate-i18n-core.js` reads `archive/legacy-i18n/i18n.js` — not the deleted nested project.
